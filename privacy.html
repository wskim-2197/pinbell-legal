핀벨(PinBell) 개인정보처리방침

시행일: 2026-11-07
운영자: Wesley Kim
개인정보 문의: wesley.devlab@gmail.com

Wesley Kim(이하 “운영자”)는 장소 도착 알림 앱 핀벨(PinBell)(이하 “서비스”)을 제공하면서 개인정보 보호법 등 관련 법령을 준수하고자 합니다. 이 방침은 서비스에서 어떤 정보를 처리하고, 외부 서비스 제공자에게 어떤 정보가 전달될 수 있으며, 사용자가 어떻게 이를 통제할 수 있는지 설명합니다.

1. 서비스 및 계정

핀벨은 사용자가 지도에서 장소를 지정하고 그곳에서 할 일을 등록하면 기기가 해당 장소 도착을 감지하여 알림을 보내는 앱입니다. 회원가입·로그인 기능은 없고, 운영자의 별도 계정 서버도 없습니다.

사용자가 직접 등록한 장소명, 좌표, 감지 반경, 장소 별칭, 할 일 내용과 일정, 완료 상태, 도착 및 알림 이력은 원칙적으로 앱의 기기 내 데이터베이스에 저장됩니다. 운영자는 이 데이터를 보관하는 자체 서버를 운영하지 않으며, 이러한 원문 데이터를 운영자의 서버로 업로드하지 않습니다. 다만 아래에서 설명하는 지도, 주소 검색, 음성 인식, Firebase 및 모델 다운로드 서비스의 별도 외부 처리는 있을 수 있습니다.

2. 처리하는 정보, 목적 및 방식

구분 처리 정보 목적 처리·전송 방식
장소 알림 위치 권한에 따라 파악되는 기기의 위치, 등록 장소 좌표·반경, 지오펜스 진입·이탈 상태 등록 장소 접근 감지와 도착 알림 Android 및 Google Play 서비스의 위치·지오펜스 기능 이용. 등록 정보와 결과는 기기 내 보관; 관련 Google 서비스가 자체 운영상 기술 정보를 처리할 수 있음
할 일 관리 장소 이름·별칭, 할 일 제목·반복 일정·완료 여부, 알림 기록 할 일 저장·조회·수정·완료 앱 기기 내 데이터베이스에 저장. 운영자 자체 서버로 업로드하지 않음
지도 지도 화면 표시 및 사용자가 허용한 경우 현재 위치 지도 표시, 지정 장소 확인 Google Maps SDK 이용. SDK가 서비스 제공을 위한 연결·기술 정보를 처리할 수 있음
주소 검색 사용자가 입력한 주소·건물명 검색어, 검색 결과 장소 검색 Daum(카카오) 우편번호 검색 WebView/스크립트 사용. 검색 요청이 카카오 서비스로 전송될 수 있음
음성 입력(선택) 마이크로 입력한 음성 및 변환된 문장 음성을 할 일 입력 문장으로 변환 Android SpeechRecognizer. 지원 시 기기 내 인식을 우선하지만, 기기 설정과 인식 서비스에 따라 Google 등 외부 음성 인식 제공자에게 음성 정보가 전송될 수 있음. 핀벨은 별도의 음성 녹음 파일을 저장하지 않음
AI 문장 이해(선택) 사용자가 입력한 문장과 등록 장소 이름 등 해석에 필요한 기기 내 정보 문장을 구조화한 할 일 초안 생성 사용자가 직접 모델을 내려받은 후 기기에서 실행. AI 추론을 위한 입력 문장을 운영자나 AI API 서버로 전송하지 않음
AI 모델 다운로드(선택) 모델 파일 다운로드 요청 시 통신·접속 정보 Gemma 모델 파일 다운로드 Hugging Face의 모델 파일 호스팅 서비스와 통신. 서버가 IP 주소 등 통신 정보를 처리할 수 있음
기능 사용 통계(선택 동의) 화면 조회, 기능 사용 횟수·결과, 오류 유형의 제한된 범주형 이벤트, 일부 앱·기기 기술정보 및 Firebase 식별자 기능 사용 흐름 및 서비스 개선 Firebase Analytics. 기본 수집 OFF, 사용자가 동의한 경우에만 수집. 장소명·좌표·할 일 원문·검색어·별칭·음성 원문 및 개별 장소 ID를 맞춤 이벤트에 싣지 않음
앱 오류 보고(별도 선택 동의) 크래시 스택 트레이스, 예외·오류정보, 기기 모델·운영체제·앱 버전, Crashlytics 설치 식별자 등 오류 파악·안정성 개선 Firebase Crashlytics. 기본 자동 전송 OFF, 사용자가 별도 허용한 경우 활성화. 운영자는 할 일·장소 원문을 진단 사용자 정의 키로 의도적으로 첨부하지 않음
환경 설정 배포 앱 버전, OS 버전, 국가·언어·시간대 등 서비스 구성에 필요한 기술 정보 및 Firebase 설치 식별자 앱 동작·설정값 제공 Firebase Remote Config와 종속 SDK(Firebase Installations 등)가 필요한 기술 정보를 자동 처리할 수 있음

사용자 위치를 지속적으로 자체 기록하거나 이동 경로를 저장하는 기능은 제공하지 않습니다. 상시 GPS 폴링을 사용하지 않으며, OS 지오펜스 이벤트와 필요 시의 일회성·화면 표시 위치 조회를 이용합니다. 다만 기기의 절전 정책 및 위치 서비스 환경에 따라 도착 알림은 지연되거나 누락될 수 있습니다.

3. 앱 권한

권한 이용 목적 허용하지 않으면
정확한·대략적 위치, 앱 사용 중 위치 지도에서 현재 위치 확인, 장소 지정 현재 위치 기능이 제한됨
백그라운드 위치 앱을 닫거나 사용하지 않을 때 등록 장소 도착 감지 앱을 사용하지 않는 동안 도착 알림이 작동하지 않을 수 있음
알림(지원 OS) 도착 알림 표시 도착해도 알림이 표시되지 않을 수 있음
마이크 사용자가 선택한 음성 입력 키보드·수동 입력은 계속 이용 가능
부팅 완료 수신 재부팅 후 도착 알림 감시 복구 앱에서 요구하는 OS 동작에 사용
인터넷 지도·주소 검색·모델 다운로드·Firebase 구성 및 선택 동의 데이터 처리 온라인 의존 기능 제한

위치 권한은 장소 도착 알림을 위해 필요한 범위에서 이용하며, 광고 타기팅이나 사용 통계 이벤트의 위치 추적 목적으로 이용하지 않습니다. 권한은 Android 시스템 설정에서 언제든 변경할 수 있습니다.

5. 정보 보유 기간 및 파기

  • 기기 내 장소·할 일·별칭·알림 기록: 사용자가 직접 삭제하거나 설정의 모든 데이터 삭제를 실행하거나 앱을 제거할 때까지 기기 내 보관합니다.
  • OS에 등록한 지오펜스 및 예약된 알림: 해당 장소·할 일을 삭제하거나 모든 데이터를 삭제할 때 등록 해제·취소합니다.
  • 다운로드한 AI 모델: 설정의 AI 모델 삭제 기능으로 삭제할 수 있으며 앱 제거 시 앱 전용 저장공간과 함께 삭제됩니다. 모든 데이터 삭제가 모델 파일까지 삭제하는지는 실제 출시 구현의 동작에 따라 별도로 안내합니다.
  • Firebase 및 기타 외부 제공자에 전달된 데이터: 운영자가 설정한 보관 기간 및 해당 서비스의 정책에 따라 처리됩니다. 기기에서 앱을 삭제해도 이미 외부 서비스에 전송된 진단·통계 자료가 즉시 모두 삭제되는 것은 아닙니다.

운영자는 관련 법령에 따른 보존 의무가 있는 경우 해당 기간 동안 법적 요구에 맞게 처리합니다.

6. 이용자의 권리와 선택

사용자는 앱에서 장소·할 일을 수정·삭제하고, 위치·알림·마이크 권한을 변경하며, 사용 통계 및 오류 보고 수집 동의를 각각 별도로 켜거나 끌 수 있습니다. 동의하지 않아도 기본적인 수동 등록과 이용 가능한 장소 관리 기능은 유지됩니다. AI 모델 설치는 선택이며 언제든 삭제할 수 있습니다.

외부 서비스에 이미 전송된 정보에 대한 열람·정정·삭제·처리정지 등 요청은 wesley.devlab@gmail.com로 문의할 수 있습니다. 계정이 없고 외부 데이터가 앱 설치 식별자 등으로 처리되기 때문에, 특정 정보의 식별 또는 삭제 가능 여부는 관련 서비스 제공자의 정책과 기술적 범위에 따라 달라질 수 있습니다.

7. 안전성 확보 조치

운영자는 기기 내부 저장을 기본으로 하고, 서비스 운영상 불필요한 원문 정보를 Analytics 맞춤 이벤트에 포함하지 않도록 허용 목록을 적용합니다. 외부 서비스와의 통신은 해당 제공자의 보안 기능을 이용하며, 앱의 권한은 기능에 필요한 범위에서 요청합니다. 오류 로그에는 사용자가 입력한 장소·할 일·음성 원문이 포함되지 않도록 개발·점검 과정에서 주의합니다.

8. 아동의 개인정보

핀벨은 아동을 주된 대상으로 설계된 서비스가 아닙니다. 실제 Google Play의 타깃 연령 설정과 이용 조건은 출시 설정에 맞춰 운영합니다.
